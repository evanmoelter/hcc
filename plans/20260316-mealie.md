# Plan: Add Mealie Recipe Manager

## Overview

Deploy [Mealie](https://mealie.io/) as a recipe management app at `food.${SECRET_DOMAIN}` (food.evmo.io) with a dedicated per-app CNPG PostgreSQL cluster, OIDC authentication via Authentik, and external ingress (same pattern as Authentik).

## Dependencies

| Dependency | Purpose | Status |
|------------|---------|--------|
| cloudnative-pg | CNPG operator | Deployed |
| longhorn | Persistent storage | Deployed |
| authentik | OIDC identity provider | Deployed |
| bjw-s/app-template | Helm chart (4.6.2) | Available |

## Architecture

```
User Browser
    │
    └─► food.${SECRET_DOMAIN} ──► Cloudflare ──► ingress-nginx-external ──► Mealie (:9000)
                                                                               │
                                                                               ├─► mealie-pg (per-app CNPG cluster)
                                                                               └─► /app/data (PVC)
```

## Implementation Steps

### Step 1: Create Authentik OAuth2/OIDC Provider

In Authentik admin (`https://sso.${SECRET_DOMAIN}/if/admin/`):

Per the [official Authentik integration guide](https://integrations.goauthentik.io/documentation/mealie/).

1. **Create Application with Provider**:
   - Navigate to **Applications > Applications > Create with Provider**
   - Select **OAuth2/OpenID Connect**
   - Configure:
     - **Name**: `Mealie`
     - **Authorization flow**: `default-provider-authorization-explicit-consent`
     - **Client type**: `Confidential`
     - **Client ID**: Generate or set a value (save for secrets)
     - **Client Secret**: Generate (save for secrets)
     - **Redirect URIs** (both `Strict`):
       ```
       https://food.${SECRET_DOMAIN}/login
       https://food.${SECRET_DOMAIN}/login?direct=1
       ```
     - **Signing Key**: `authentik Self-signed Certificate`
     - **Scopes**: `openid`, `profile`, `email`

2. **Application settings** (created alongside the provider):
   - **Name**: `Mealie`
   - **Slug**: `mealie`
   - **Launch URL**: `https://food.${SECRET_DOMAIN}`

### Step 3: Create Flux Kustomization (`mealie/ks.yaml`)

```yaml
---
# yaml-language-server: $schema=https://kubernetes-schemas.pages.dev/kustomize.toolkit.fluxcd.io/kustomization_v1.json
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: &app mealie
  namespace: flux-system
spec:
  targetNamespace: default
  commonMetadata:
    labels:
      app.kubernetes.io/name: *app
  dependsOn:
    - name: cloudnative-pg
    - name: longhorn
    - name: authentik
  path: ./kubernetes/main/apps/default/mealie/app
  prune: true
  sourceRef:
    kind: GitRepository
    name: home-kubernetes
  wait: true
  interval: 30m
  retryInterval: 1m
  timeout: 5m
  postBuild:
    substitute:
      APP: *app
```

### Step 4: Create CNPG Cluster (`mealie/app/cluster.yaml`)

CNPG auto-generates credentials into the `mealie-pg-app` secret (contains `uri`, `host`, `port`, `dbname`, `username`, `password`).

```yaml
---
# yaml-language-server: $schema=https://kubernetes-schemas.pages.dev/postgresql.cnpg.io/cluster_v1.json
apiVersion: postgresql.cnpg.io/v1
kind: Cluster
metadata:
  name: mealie-pg
spec:
  instances: 1
  imageName: ghcr.io/cloudnative-pg/postgresql:18.1-system-trixie
  primaryUpdateStrategy: unsupervised

  storage:
    size: 10Gi
    storageClass: longhorn

  enableSuperuserAccess: false

  postgresql:
    parameters:
      max_connections: "100"
      shared_buffers: 64MB

  bootstrap:
    initdb:
      database: mealie
      owner: mealie

  backup:
    retentionPolicy: 90d
    barmanObjectStore:
      data:
        compression: bzip2
      wal:
        compression: bzip2
        maxParallel: 4
      destinationPath: s3://tf-hcc-cloudnativepg/
      endpointURL: https://${SECRET_CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com
      serverName: mealie-pg-v1
      s3Credentials:
        accessKeyId:
          name: mealie-pg-r2
          key: R2_ACCESS_KEY_ID
        secretAccessKey:
          name: mealie-pg-r2
          key: R2_SECRET_ACCESS_KEY
```

### Step 7: Create Secrets (`mealie/app/secret.sops.yaml`)

Two secrets in one file (same pattern as Home Assistant): app secrets and R2 backup credentials.

Before encrypting with SOPS:

```yaml
---
apiVersion: v1
kind: Secret
metadata:
  name: mealie-secret
type: Opaque
stringData:
  # OIDC
  OIDC_CLIENT_ID: <from-authentik-step-1>
  OIDC_CLIENT_SECRET: <from-authentik-step-1>
---
apiVersion: v1
kind: Secret
metadata:
  name: mealie-pg-r2
type: Opaque
stringData:
  R2_ACCESS_KEY_ID: <r2-access-key>
  R2_SECRET_ACCESS_KEY: <r2-secret-key>
```

Create R2 API token scoped to the `tf-hcc-cloudnativepg` bucket, then encrypt:
`sops --encrypt --in-place kubernetes/main/apps/default/mealie/app/secret.sops.yaml`

### Step 8: Create HelmRelease (`mealie/app/helmrelease.yaml`)

Database credentials come from the CNPG auto-generated `mealie-pg-app` secret — no postgres-init container needed.

```yaml
---
# yaml-language-server: $schema=https://raw.githubusercontent.com/bjw-s/helm-charts/app-template-4.6.2/charts/other/app-template/schemas/helmrelease-helm-v2.schema.json
apiVersion: helm.toolkit.fluxcd.io/v2
kind: HelmRelease
metadata:
  name: &app mealie
spec:
  interval: 30m
  chart:
    spec:
      chart: app-template
      version: 4.6.2
      sourceRef:
        kind: HelmRepository
        name: bjw-s
        namespace: flux-system

  values:
    controllers:
      mealie:
        annotations:
          reloader.stakater.com/auto: "true"

        pod:
          securityContext:
            runAsUser: 568
            runAsGroup: 568
            runAsNonRoot: true
            fsGroup: 568
            fsGroupChangePolicy: OnRootMismatch

        containers:
          app:
            image:
              repository: ghcr.io/mealie-recipes/mealie
              tag: v3.12.0
            env:
              TZ: ${TIMEZONE}
              # Application
              ALLOW_SIGNUP: "false"
              BASE_URL: https://food.${SECRET_DOMAIN}
              # Database
              DB_ENGINE: postgres
              POSTGRES_PORT: "5432"
              POSTGRES_DB: mealie
              POSTGRES_SERVER:
                valueFrom:
                  secretKeyRef:
                    name: mealie-pg-app
                    key: host
              POSTGRES_USER:
                valueFrom:
                  secretKeyRef:
                    name: mealie-pg-app
                    key: username
              POSTGRES_PASSWORD:
                valueFrom:
                  secretKeyRef:
                    name: mealie-pg-app
                    key: password
              # OIDC
              OIDC_AUTH_ENABLED: "true"
              OIDC_PROVIDER_NAME: authentik
              OIDC_SIGNUP_ENABLED: "true"
              OIDC_CONFIGURATION_URL: https://sso.${SECRET_DOMAIN}/application/o/mealie/.well-known/openid-configuration
              OIDC_AUTO_REDIRECT: "true"
              OIDC_REMEMBER_ME: "true"
              OIDC_ADMIN_GROUP: mealie-admins
              OIDC_USER_GROUP: mealie-users
            envFrom:
              - secretRef:
                  name: mealie-secret
            probes:
              liveness:
                enabled: true
              readiness:
                enabled: true
              startup:
                enabled: true
                spec:
                  failureThreshold: 30
                  periodSeconds: 5
            securityContext:
              allowPrivilegeEscalation: false
              readOnlyRootFilesystem: true
              capabilities:
                drop: ["ALL"]
            resources:
              requests:
                cpu: 50m
                memory: 256Mi
              limits:
                memory: 512Mi

    service:
      app:
        controller: mealie
        ports:
          http:
            port: 9000

    ingress:
      app:
        className: external
        annotations:
          external-dns.alpha.kubernetes.io/target: external.${SECRET_DOMAIN}
        hosts:
          - host: &host food.${SECRET_DOMAIN}
            paths:
              - path: /
                service:
                  identifier: app
                  port: http
        tls:
          - hosts:
              - *host

    persistence:
      data:
        enabled: true
        existingClaim: mealie-data
        advancedMounts:
          mealie:
            app:
              - path: /app/data
      nltk-data:
        type: emptyDir
        globalMounts:
          - path: /nltk_data
      tmp:
        type: emptyDir
        globalMounts:
          - path: /tmp
```

## Post-Deployment Checklist

- [ ] R2 API token created for `mealie-pg-r2` secret
- [ ] Authentik provider and application created with correct redirect URIs
- [ ] Authentik groups created (`mealie-admins`, `mealie-users`)
- [ ] Secrets encrypted with SOPS and committed
- [ ] App registered in `default/kustomization.yaml`
- [ ] CNPG cluster healthy (`kubectl get cluster mealie-pg -n default`)
- [ ] Scheduled backup configured and first backup completed
- [ ] Flux reconciliation completes without errors
- [ ] PVC created and bound
- [ ] Mealie pod healthy (all probes passing)
- [ ] `food.${SECRET_DOMAIN}` reachable via external ingress
- [ ] DNS record created by external-dns pointing to Cloudflare
- [ ] OIDC login redirects to Authentik and returns successfully
- [ ] Admin user has correct role via group mapping

## Rollback Plan

1. Remove `mealie/ks.yaml` from `default/kustomization.yaml` and commit
2. Flux will prune all Mealie resources (including the CNPG cluster)
3. PVC will be retained (unless manually deleted) for data recovery
4. Database backups remain in R2 under `mealie-pg-v1` for recovery if needed

## Notes

- Mealie listens on port 9000 by default
- The `/nltk_data` emptyDir is needed for Mealie's NLP recipe parsing features
- `OIDC_AUTO_REDIRECT: "true"` skips the login page and goes straight to Authentik — set to `"false"` if you want to keep password login visible
- No `postgres-init` container needed — CNPG handles database/user creation via `bootstrap.initdb`, and credentials are auto-generated into the `mealie-pg-app` secret
- This follows the per-app CNPG cluster pattern established by Home Assistant (and planned for all apps in plan 11)
- All 5 reference implementations use Mealie v3.12.0 with the `app-template` chart
- The `readOnlyRootFilesystem` + emptyDir `/tmp` pattern follows security best practices seen across the reference implementations

## k3s Compatibility

Fully compatible with k3s. No special considerations required.
